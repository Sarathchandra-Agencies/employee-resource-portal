# Employee Resource Portal

An internal resource portal for **Sarathchandra Agencies** that provides employees with quick access to commonly used forms, documents, and printable resources.

The portal acts as a central library for prebuilt interactive HTML forms such as warranty cards, registrations, service documents, inspection sheets, certificates, labels, and other internal resources.

---

## Overview

The Employee Resource Portal is designed to make internal documents easier to find and use.

Employees can:

- Browse available forms
- Search by form name or category
- Filter documents by category
- Open existing interactive HTML forms
- Complete forms directly in the browser
- Print documents when required

The homepage serves as the central navigation layer while each form remains an independent HTML document.
